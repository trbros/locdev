# CLI

`locdev` はターミナルからデーモンを操作します。アプリと CLI は同じデーモンと通信するので、アプリでできることはすべてここからもできます。すべてのコマンドが機械で読める出力のための `--json` を受け付け、`locdev <command> --help` でオプションを確認できます。

サイトのコマンド (`up`、`down`、`reload`、`logs`、`info`、`open`、`secure`、`dev …`) はサイト名を受け取ります。省略すると、現在のディレクトリを含む登録済みのサイトが使われます。

```bash
cd ~/Code/shop
locdev up            # locdev up shop と同じ
locdev logs -f
locdev secure
```

**管理者権限が必要** と付いたコマンドは、正確な変更内容 (スクリプト) を表示し、管理者権限を使う前に確認を求めます。`--yes` で確認を省略できます。この手順なしにシステムへ何かがインストールされることはありません。

## ターミナル UI (TUI)

対話型ターミナルで `locdev` を単独で実行すると TUI が開きます (`locdev tui` と同じ。`--light` で明るい配色)。見た目はアプリと同じです。サイドバーにページ、LED 付きのサイトとサービス、下部にプロキシ・DNS・HTTPS・Mailbox の状態、中央にページ (ダッシュボード、サイト、サービス、ランタイム、プロセス、Mailbox、アクティビティ、Doctor、そして CLI とデーモンのバージョンを表示する「このアプリについて」) があります。

| キー          | 動作                                                              |
| ------------- | ----------------------------------------------------------------- |
| `↑` `↓` `tab` | リスト内を移動。`tab` でサイドバーとページを切り替え              |
| `enter`       | ページ、サイトやサービスの出力、メッセージを開く                  |
| `s` · `R`     | 選択中のサイト・サービス・プロセスを開始/停止 · 再起動            |
| `o` · `l`     | サイトをブラウザーで開く · 出力を表示                             |
| `ctrl+p`      | 「移動または実行」: ページ、サイト、操作、すべての CLI コマンド   |
| `:`           | 任意の `locdev` コマンドをその場で実行 (確認やパスワード入力も可) |
| `/` · `?`     | リストを絞り込む · すべてのキーを表示                             |
| `q`           | 終了 (デーモンとサイトは動き続けます)                             |

TUI に専用画面がない操作は `:` から実行します (例: `:git commit -m "…"`)。ターミナルをコマンドに渡し、終了すると TUI に戻ります。対話型ターミナルがない場合 (パイプや `--json`)、コマンドなしの `locdev` はヘルプを表示します。

## 終了コード

| コード | 条件                                                                             |
| ------ | -------------------------------------------------------------------------------- |
| `0`    | 成功。                                                                           |
| `1`    | エラー (メッセージに対処方法が表示されます)。`doctor` がエラーを見つけたときも。 |
| `3`    | デーモンが停止している状態での `locdev status`。                                 |
