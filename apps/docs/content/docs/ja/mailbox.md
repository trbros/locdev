# Mailbox

LocDev には専用のテスト用受信箱があります。**受け取るだけ**の SMTP サーバーです。`127.0.0.1:1025` (Mailpit がすでに使っていれば次の空きポート) で待ち受け、受け取ったものをすべて保存し、誰にも配信しません。追加でインストールするツールはありません。

![Tools → Mailbox: サイトごとの受信箱、隔離された HTML、デバッグタブ。](screenshot:mailbox)

```bash
locdev mail enable shop          # shop のメールを Mailbox に送る
locdev mail list                 # メッセージ (新しい順)
locdev mail show <id>            # エンベロープ、テキスト、リンク、添付、問題点
locdev mail raw <id> -o msg.eml  # 届いたままのメッセージ
locdev mail test                 # Mailbox にテストメッセージを送る
```

アプリでは **ツール → Mailbox** です。サイトで有効にするには **Site → Settings → mail** を使います。

## フレームワークごとの接続方法

LocDev は通信を横取りしません。SMTP のトランスポートを明示的に設定しますが、それは**サイトのプロセス (サーバー、ワーカー、スケジューラー) の環境の中だけ**です。プロジェクトの `.env` を編集することはありません。有効・無効を切り替えたら、サイトを再起動してください。

| スタック                    | 方法                                                                                                                                                                                                                                                                                                                                                                    |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Laravel                     | `MAIL_MAILER=smtp`、`MAIL_HOST`、`MAIL_PORT`、`MAIL_USERNAME` (サイト名)、`MAIL_PASSWORD`。さらに、プロジェクトの `config/mail.php` が読むものに応じて `MAIL_SCHEME` (Laravel 11 以降) または `MAIL_ENCRYPTION=null` (10 以前)。既存の `MAIL_URL` は `MAIL_HOST` より優先されるので、無効にします。                                                                     |
| WordPress と PHP            | PHP の `mail()` は `sendmail_path` を通ります。これは `PHP_INI_SCAN_DIR` で追加する LocDev の `.ini` で設定します (システムの `.ini` もそのまま有効)。Windows では `.ini` で `SMTP`/`smtp_port` を使います。SMTP プラグイン (WP Mail SMTP など) は `mail()` を通らないので、それらも `127.0.0.1` に向ける必要があります。                                               |
| Node.js、Django、Rails など | プロジェクトの `.env`/`.env.example` にすでに `SMTP_*`、`MAIL_*`、`EMAIL_*`、`MAILER_*` の変数 (`HOST`、`PORT`、`USER`、`PASS`、`SECURE`、`URL` など) があれば、LocDev は同じ変数を設定します。フレームワークがコードから直接 SMTP を読む場合 (`settings.py`、`development.rb`、`nodemailer.createTransport`)、開発環境に追加すべきコードがそのまま画面に表示されます。 |

各サイトの SMTP ユーザーはサイト名で、Mailbox はそれで各メッセージがどのプロジェクトから来たかを知ります。サーバーはどんなパスワードでも受け付け、STARTTLS は提供しません (ループバックのため)。

### 本物の SMTP: あなたの許可があるときだけ

プロジェクトが本物のサーバーを指している場合、Mailbox を有効にするには**明示的な同意が必要**です。`locdev mail enable --override-real`、またはアプリの "Allow replacing it" チェックボックスです。ローカルでないホストや、SES、Postmark、Mailgun、Resend などの API トランスポートが対象です。`.env` のパスワードが画面に表示されることはありません。

## 受信箱

- **整理:** 全体の受信箱とサイトごとの受信箱。件名、送信者、宛先、本文の一部で検索でき、未読と添付ありで絞り込めます。
- **表示:** HTML、テキスト、ヘッダー、リンク、添付 (ダウンロード可)、元の `.eml`。
- **Debug:** SMTP セッションが実際に伝えた内容を表示します。
  - エンベロープ (`MAIL FROM`、`RCPT TO`) と `HELO`。
  - プロトコル (認証したときは `ESMTPA`) と `AUTH` のユーザー。
  - 送信元アドレス、到着時刻、メッセージの `Date`、サイズ、サイトのフレームワーク。
- **書式の問題:** 客観的なチェックです。
  - `From`、`Date`、`Message-ID`、`Subject` の欠落と、不正な `Date` (RFC 5322)。
  - 998 文字を超える行と、MIME なしの 8 ビットの内容。
  - デコードのエラー (base64、quoted-printable、文字セット)。
  - テキストの代替がない HTML と、対応するパートのない `cid:`。

### 隔離された HTML

メールの HTML は空の `sandbox` を持つ `iframe` で表示され、スクリプト、フォーム、ページ移動、ポップアップは動きません。さらにセキュリティポリシーがネットワークからの読み込みをすべてブロックするので、トラッキングピクセルやリモートの画像は読み込まれません。ブロックしたリモートリソースの数が画面に表示され、Debug タブにその一覧があります。埋め込み画像 (`cid:`) は普通に表示されます。メール内のリンクはクリックしても開きません。Links タブを使うと、ブラウザーでそのアドレスを開けます。

キャプチャした各メッセージは通知にもなり (_キャプチャしたメール_ カテゴリー)、アプリが前面にないときはシステムが表示し、トレイアイコンの緑の点が点灯します ([アプリの紹介](/docs/app))。メッセージを開くか削除すると、通知は既読になります。

## 保存

メッセージは `data/mail/messages` (`0700` のフォルダー) に、`.eml` とエンベロープを含む `.json` のペアで保存されます。保持するのは最新の 1,000 件で、25 MB を超えるメッセージは拒否します。削除するには `locdev mail delete`、`locdev mail clear [site]`、またはアプリのボタンを使います。

> [!WARNING]
> Laravel では、LocDev は `artisan serve` を `--no-reload` 付きで実行します。これがないと、`serve` は PHP サーバーを起動する前に LocDev が渡した変数を捨ててしまいます (PHP のビルドは `variables_order=EGPCS` です)。`.env` を編集したら、サイトを再起動してください。
