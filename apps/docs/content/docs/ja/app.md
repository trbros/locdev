# アプリの紹介

アプリはメインページと、それぞれのサブページで構成されています。左にサイドバー、下にステータスバーがあり、デーモン、プロキシ、DNS、HTTPS の状態をひと目で確認できます (各項目をクリックすると対応する設定に移動します)。

## 起動

起動すると小さなウィンドウに LocDev のマークが描かれ、**起動トレース** (デーモン → プロキシ → DNS → HTTPS) が表示されます。各ノードはデーモンから読んだ実際の状態で点灯します (すべて正常なら緑、HTTPS がまだ信頼されていないなど注意つきで動いている場合は黄、失敗したら赤)。インターフェースのデータがそろうと、マークの衛星が「軌道を離れ」、メインウィンドウに切り替わります。スプラッシュが起動を 8 秒以上止めることはなく、テーマとアニメーションの設定に従います。

## ナビゲーション

![ダッシュボード: 環境の状態、起動中のサイト、対応が必要なもの。](screenshot:dashboard)

サイドバーには**展開** (アイコンと名前) と**折りたたみ** (アイコンのみ、ツールチップ付き) の 2 つのモードがあります。`Ctrl` `B` か下部のボタンで切り替えられ、選択は保存されます。幅の狭いウィンドウでは常に折りたたまれます。`↑` `↓` キーで項目を移動できます。

![折りたたんだサイドバー](screenshot:sidebar-collapsed)

サイドバーでサブメニューを持つのは**ツール**だけです。ほかのサブページはページ内にあります。ランタイムと各サイトではタブ、設定では横のナビゲーションです。各ページにはパス (パンくずリスト) と戻る/進むボタン (`Alt` `←` / `Alt` `→`、またはマウスのサイドボタン) があります。

| ページ         | 内容                                                                                                                                                                                    |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ダッシュボード | 環境の状態、稼働中の環境、アラート (失敗したサイト、Doctor、ランタイム)、最近のアクティビティ                                                                                           |
| サイト         | サイト一覧と各サイトの詳細: 概要、サーバー、依存関係、環境、Config、Email Studio、Deploy、Git、GitHub (GitHub のリモートがある場合)、設定                                               |
| ランタイム     | 概要 (各サイトが何をなぜ使っているか)、Node.js、PHP、パッケージマネージャー                                                                                                             |
| Services       | データベースとキャッシュのインストールとインスタンス ([サービス](/docs/services))                                                                                                       |
| ツール         | [新しいプロジェクトとインストーラー](/docs/new-project)、プロセスとログ、[Database](/docs/database)、[Mailbox](/docs/mailbox)、[Actions builder](/docs/actions)、コマンドライン、Doctor |
| 通知           | 未処理、履歴、設定 ([詳細](/docs/dependencies))                                                                                                                                         |
| 設定           | 概要、デーモン、プロキシ、DNS、監視フォルダー、HTTPS、自動化、フレームワーク、環境、セキュリティ、連携、アップデート、外観、ショートカット、このアプリについて                          |

## タイトルバー

上部のバーはシステムではなくアプリ自身のものです。左にはデーモンの状態を示す LED と現在の場所 (`locdev › sites · shop`)、中央にはコマンドパレットを開く検索、右には最小化、最大化、閉じるボタンがあります。バーをドラッグするとウィンドウが動き、ダブルクリックで最大化します。閉じても、これまでどおりアプリはトレイに隠れるだけです。macOS では、システム自身のボタンがバーの上に残ります。

## サイト

![サイト画面](screenshot:sites)

- **左の一覧:** サイトは _実行中_ と _停止中_ に分かれ、状態 LED、プロジェクトの種類、ポートが表示されます。`Ctrl` `F` で絞り込めます。
- **タブ:** ブラウザーと同じく、各サイトはタブで開きます。一覧のサイトをクリックすると手前のタブに表示され (すでに開いているタブがあればそこに切り替え)、`Ctrl`+クリックか中クリックで新しいタブに開きます。**+** は全サイトから選べる空のタブを開きます。タブはドラッグで並べ替え、中クリックで閉じます。各タブは表示中のサブページ (概要、サーバー、Git…) を覚えていて、アプリを開き直してもタブは戻ります。
- **アドレスバー:** サイトのアドレスと鍵アイコン (HTTPS が信頼済みなら緑。琥珀色は CA の信頼設定へ)、フレームワーク、状態、操作 (起動、停止、再起動、ブラウザーで開く、フォルダーを表示、**⋯** メニュー)。アドレスをクリックしてサイト名の一部を入力すると移動できます。`Enter` でこのタブに、`Ctrl` `Enter` で新しいタブに開きます。サブドメイン (`api.shop.test`) はそのサイトに移動します。
- **概要:** パス、コマンド、プロセス、サイトが使うランタイムと各バージョンの出どころ (固定、`.nvmrc`、`engines`、デフォルト)、範囲を満たさない場合やサポート外のバージョンへの警告。
- **サーバー:** プロセスのライブ出力。stderr は黄、LocDev 自身のメモは斜体で表示されます。表示のクリア、出力のコピー、自動スクロールの一時停止ができます。
- **設定:** コマンド、ポート、ランタイムとパッケージマネージャーのバージョン、LocDev と一緒の起動、サイトのドメインと HTTPS の状態。

![サイトの設定](screenshot:site-settings)

プロセスが失敗すると、理由が強調表示され、出力に移動できます。

![mysqli 拡張がないために失敗した WordPress。](screenshot:site-failed)

一覧のサイトを右クリックするか **⋯** メニューで、同じ操作ができます。ブラウザーで開く、起動/停止、再起動、新しいタブで開く、編集、フォルダーを表示、URL やパスのコピー、削除です。削除は確認を求め、**ファイルを消すことはありません**。

## トレイ

アプリが開いている間、LocDev はシステムトレイにあります。Linux と Windows では、デーモンが動いているとアイコンがオレンジ、止まっているとグレーになります。macOS ではほかのメニューバーアイコンと同じモノクロで、状態はメニューに表示されます。メニューには起動中のサイト数と、サイトごとの _ブラウザーで開く_、_起動_/_停止_、_再起動_、さらにアプリを開く操作とデーモンの起動・停止・再起動があります。

### 色付きの点

読むものがあると、トレイアイコンの隅に点が表示されます。色で内容がわかります。

| 色  | 意味                                                              |
| --- | ----------------------------------------------------------------- |
| 青  | 未読の通知 (更新、失敗、ジョブの結果など)                         |
| 緑  | [Mailbox](/docs/mailbox) がキャプチャした、まだ開いていないメール |
| 紫  | その両方                                                          |

アイコンのツールチップとメニューに件数が表示され (例: _3 unread notifications, 1 unread email (violet dot)_)、メニューの項目から通知や Mailbox を開けます。すべて読むと点は消えます。macOS では、点が表示されている間は色が見えるよう、アイコンがモノクロではなくなります。

ウィンドウを閉じてもアプリは隠れるだけで、トレイに残ります。終了するにはメニューの _LocDev を終了_ を使います。終了するのはアプリだけで、デーモンは CLI と同じようにサイトを提供し続けます (`locdev stop` でデーモンを停止)。LocDev をもう一度開くと開いていたウィンドウが戻ってくるので、トレイのないデスクトップでもこれで戻れます。

> [!NOTE]
> GNOME ではトレイアイコンに AppIndicator 拡張が必要です。Ubuntu では最初から有効です。ほかのディストリビューションでは _AppIndicator and KStatusNotifierItem Support_ 拡張をインストールしてください。

## コマンドパレット

`Ctrl` `K` (macOS では `⌘` `K`) でパレットが開きます。サイトの起動・停止・表示、デーモンの操作、任意のページやサブページへの移動ができます。

![コマンドパレット](screenshot:palette)

主なショートカット: `Ctrl` `K`(パレット)、`Ctrl` `N`(サイトを追加)、`Ctrl` `1` … `7`(ページ)、`Ctrl` `,`(設定)、`Ctrl` `T`/`Ctrl` `W`/`Ctrl` `Tab`(サイトタブ)、`Alt` `←`/`→`(戻る/進む)。すべて **設定 → ショートカット** で変更できます。一覧は[キーボードショートカット](/docs/shortcuts)にあります。

## 設定

![設定: 概要](screenshot:settings)

概要には各項目の状態がまとまっていて、各行からサブページに移動できます。

- **デーモン:** プロセス、稼働時間、IPC エンドポイント、起動/停止/再起動、_ログイン時に LocDev を起動_、設定とログのフォルダー。
- **プロキシ:** ポートと対応するドメイン。
- **[DNS](/docs/domains)** と **[HTTPS](/docs/https)** (各サイトの HTTPS の状態付き)。
- **外観:** アプリの言語、テーマ、サイドバーのモード、アニメーション (システムに従う、控えめ、すべて)。
- **連携:** GitHub アカウント、[コードエディター](/docs/editors)、[デプロイ先](/docs/deploy)。
- **[アップデート](/docs/updating)** と **[ショートカット](/docs/shortcuts)**。
- **このアプリについて:** ロゴ、アプリ・デーモン・CLI のバージョン、ビルドのコミットと日時、システムとアーキテクチャ、アップデートチャネル、ライセンス(Apache-2.0)、サードパーティソフトウェアとライセンスの一覧、バージョン履歴(changelog)、ドキュメントとリポジトリへのリンク。その下に PATH 上の CLI。

## Services

![Services: システムのインストールとインスタンス](screenshot:services)

LocDev が検出またはダウンロードしたインストールと、独自のポート、データ、ログを持つインスタンスです。[サービス](/docs/services)を参照してください。

## 言語

アプリはポルトガル語、英語、スペイン語、日本語に対応しています。デフォルトではシステムの言語に従い、**設定 → 外観** で固定できます。言語を変えるとウィンドウが再読み込みされます。トレイのメニューは、アプリが一度開いた後はアプリの言語に合わせます。デーモンからのメッセージ (エラー、ログ、doctor の結果) とプロジェクトのデータは英語のままです。

## ライトテーマとダークテーマ

アプリはシステムのテーマに従うか、_Paper_ (ライト) または _Carbon_ (ダーク) に固定できます。このドキュメントのスクリーンショットはページの言語で、サイトのテーマに合わせて切り替わります。

## アクセシビリティ

アプリは WCAG 2.2 レベル AA に準拠しています。EN 301 549、European Accessibility Act、Section 508 が参照している基準です。

- **キーボード:** マウスなしですべて操作できます。`Tab` でコントロールを移動し、フォーカスは常に表示されます。矢印キーでサイドバーとタブを移動でき、ショートカットは **設定 → ショートカット** にあります。
- **スクリーンリーダー:** アイコンだけのボタンにも名前があり、タブは `tablist`/`tab` のパターンに従い、スクロールする領域（コード、メッセージ）にもフォーカスできます。
- **コントラスト:** 両方のテーマで、テキストとボタンは 4.5:1 を超えます。
- **動き:** `prefers-reduced-motion` を尊重し、**設定 → 外観** でアニメーションを止められます。

各バージョンで、ライトとダークの両テーマのすべての画面を、キーボードだけの操作も含めて自動チェック（axe-core）しています: `make test-a11y`。

## ビジュアルアイデンティティ

LocDev のロゴは公式の PNG で、そのまま使います。元ファイルは `apps/desktop/branding/logo.png` だけで、`pnpm icons` がそれを切り抜き、中央に配置し、リサイズして、Windows (`.ico`)、macOS (`.icns`)、Linux、Tauri のアイコン、トレイアイコン、アプリとスプラッシュで使う `logo.png`、`favicon.ico` を生成します。
