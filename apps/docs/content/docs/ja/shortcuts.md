# キーボードショートカット

**設定 → ショートカット** には、アプリのすべてのショートカットがカテゴリ別に並んでいます。検索、変更、2 つ目の組み合わせの追加、削除、既定への復元ができます。`Ctrl` `/` でこのページを開きます。

![ショートカット: 検索、カテゴリ、各操作の組み合わせ。](screenshot:shortcuts)

## 動作のしくみ

- **LocDev の中だけで動作します。** ショートカットは LocDev のウィンドウが前面にあるときに働きます。LocDev はシステム全体のショートカットを登録しないため、他のアプリのキーを奪いません。
- **macOS では `Ctrl` が `⌘` になります。** ただしサイトタブの切り替え(`Ctrl` `Tab`)は例外です。macOS では `⌘` `Tab` がアプリの切り替えに使われ、LocDev に届かないためです。
- **テキスト欄では** `Ctrl`/`⌘` を含む組み合わせだけが動作します。`Alt` と矢印キーや単独のキーは、文字の編集にそのまま使われます。
- **有効な場所:** 一部のショートカットは特定のページだけで使えます(_サイト で_ と表示)。サイトタブ、フィルター、前面のタブのサイトに対する操作です。
- **保存場所:** このコンピューター上のアプリのストレージです(`settings.toml` ではありません)。変更はすべての LocDev ウィンドウにすぐ反映されます。

## ショートカットを変更する

1. 操作の横の **+** をクリックし、組み合わせを押します。`Esc` でキャンセルします。
2. 入力で誤って動かないよう、`Ctrl`、`⌘`、`Alt` のいずれか(またはファンクションキー `F1`…`F12`)が必要です。
3. ほかの操作がすでに使っている場合は、どの操作かが表示されます。**ここで使う** を押すと、ほかの操作から外されます。
4. 組み合わせにマウスを合わせると削除(**×**)できます。復元ボタンでその操作の既定に戻り、**すべて既定に戻す** ですべて元に戻ります。

琥珀色の組み合わせには注意があります:

- **競合:** 2 つの操作が同じ組み合わせを使っています。実行されるのは片方だけです(この一覧で先にある方)。
- **予約済み:** システムやテキスト編集が使う組み合わせで、LocDev に届かない場合があります。例: `Alt` `F4` と `Alt` `Tab`(Windows と Linux)、`Ctrl` `Alt` `T`(Ubuntu のターミナル)、`⌘` `Q`、`⌘` `H`、`⌘` `Tab`(macOS)、Windows/Super キーとの組み合わせ、テキスト欄での `Ctrl` `C`/`V`/`X`/`A`/`Z`。

組み込みのショートカット(鍵アイコン付き)は参照用です: Email Studio の元に戻す・やり直す、ダイアログを閉じる/フィルターをクリアする `Esc`。

## 既定

| カテゴリ       | 操作                                                                   | ショートカット                      |
| -------------- | ---------------------------------------------------------------------- | ----------------------------------- |
| 一般           | コマンドパレット                                                       | `Ctrl` `K`                          |
| 一般           | 設定                                                                   | `Ctrl` `,`                          |
| 一般           | キーボードショートカット                                               | `Ctrl` `/`                          |
| 一般           | サイドバーを折りたたむ/展開する                                        | `Ctrl` `B`                          |
| 一般           | 戻る / 進む                                                            | `Alt` `←` / `Alt` `→`               |
| ナビゲーション | ダッシュボード、サイト、ランタイム、サービス、ツール、通知、設定に移動 | `Ctrl` `1` … `Ctrl` `7`             |
| プロジェクト   | サイトを追加                                                           | `Ctrl` `N`                          |
| プロジェクト   | 新しいプロジェクトを作成                                               | `Ctrl` `Shift` `N`                  |
| プロジェクト   | サイトを絞り込む(サイト で)                                            | `Ctrl` `F`                          |
| プロジェクト   | 新しいタブ / タブを閉じる(サイト で)                                   | `Ctrl` `T` / `Ctrl` `W`             |
| プロジェクト   | 次 / 前のサイトタブ(サイト で)                                         | `Ctrl` `Tab` / `Ctrl` `Shift` `Tab` |
| プロジェクト   | サイトを[エディター](/docs/editors)で開く(サイト で)                   | `Ctrl` `E`                          |
| ログと診断     | [Debug Center](/docs/debug-center) を開く                              | `Ctrl` `Shift` `D`                  |

既定では未設定で、自由に割り当てられるもの: サイトをブラウザーで開く、サイトのフォルダーを表示、サイトの起動/停止、再起動、共有(サイト で)、各ツールを開く(コマンドライン、新しいプロジェクト、インストーラー、データベース、Mailbox、トンネル、Actions builder、Processes and logs、Doctor)。

コマンドパレット、メニュー、ボタンのヒントには、変更したものも含めて常に現在の組み合わせが表示されます。

## 制限事項

- グローバルショートカット(LocDev の外で働くもの)や、他のアプリからウィンドウを呼び出すショートカットはありません。
- TUI(ターミナルの `locdev`)には独自のキーがあり、ここでは変更できません。
- Linux のターミナルやワークスペースのショートカットはデスクトップ環境によって異なります。予約済みの一覧は一般的な既定(GNOME/Ubuntu)をカバーしていますが、すべてではありません。
