# Email Studio

各サイトの **Email Studio** タブには、プロジェクトのメールテンプレートとコンポーネントがまとまっています。ビジュアルなブロックエディター、リアルタイムのプレビュー、[Mailbox](/docs/mailbox) へのテスト送信があります。編集するのはプロジェクト自身のファイルで、Blade はそのまま保たれます。

![Email Studio: ブロック、Blade のコードを保った構造、プレビュー。](screenshot:email-studio)

```bash
locdev new email contact                   # Laravel: make:mail + ブロック付きのビュー
locdev new email receipt --markdown        # Markdown mailable
locdev new email component button          # <x-mail.button>
locdev email list                          # テンプレート、mailable、コンポーネント
locdev email preview <path> --framework    # Laravel 自身でレンダリング
locdev email send-test <path>              # Mailbox へ送信 (外部には送らない)
```

## 見つかるもの

| スタック       | テンプレート                                                                                                                                                                                                                                                                                 | コンポーネント                                                                                                                                                                                                                                      |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Laravel        | `resources/views` 内の `mail`、`mails`、`email`、`emails` フォルダーにあるビューと、`app/Mail` の Mailable が使うビュー (`view:`、`html:`、`text:`、`markdown:`)。Mailable、変数 (public プロパティと `with:` のキー)、形式 (Blade、Markdown (`<x-mail::message>`)、テキスト) を表示します。 | `resources/views/components/mail/*.blade.php`。`<x-mail.name>` として使います。プロパティは Blade 自身の `@props([...])` から取ります。Laravel の Markdown コンポーネント (`x-mail::button`、`panel` など) は Markdown テンプレートに表示されます。 |
| ほかのスタック | `emails/`、`templates/emails/` (Django)、`app/views/*_mailer/` (Rails)、`.mjml`、React Email (`.tsx`)                                                                                                                                                                                        | `<!-- locdev:component {"props":[...]} -->` 付きの `emails/components/*.html`                                                                                                                                                                       |

見つけるために何かを実行することはなく、ファイルを読むだけです。MJML、React Email、ERB、Django のテンプレートはコードとして編集します。ビジュアルブロックは Blade、Markdown mailable、HTML で使えます。

## 編集がテンプレートを保つしくみ

エディターは**セグメント**単位で動きます。

- **LocDev のブロック** (ヘッダー、見出し、テキスト、ボタン、画像、カラム、区切り線、余白、フッター、パネル、コンポーネント)。それぞれがテンプレート内の 2 つのコメントで囲まれ、コメントは送信されるメールには含まれません。

  ```blade
  {{-- locdev:block {"type":"button","props":{"text":"Pay","url":"{{ $url }}"},"h":"3fa1c2d0"} --}}
  <tr><td …><a href="{{ $url }}" …>Pay</a></td></tr>
  {{-- /locdev:block --}}
  ```

  テキストには Blade の式 (`{{ $user->name }}`) を書け、書いたとおりにファイルへ入ります。それ以外はエスケープされます。コンポーネントでは、`$` で始まる値はバインディング (`:url="$url"`) になります。
- **コード:** ブロックの外にあるもの (`@if`、`@foreach`、`{!! !!}`、`@props`、レイアウトなど) はすべてそのまま保存されます。コードはドラッグしたりテキストとして編集したりできますが、**ビジュアルエディターがコードを書き換えることはありません**。

変更せずに開いて保存すると、ファイルはバイト単位で同じになります。ブロックを変更すると、そのブロックの行だけが変わります。

**IDE で編集しましたか?** 各ブロックは自分が生成したマークアップのハッシュを持っています。LocDev の外で変更されていると、ブロックは*編集済み*と表示され、**プロパティから再生成** を選ぶまで、あなたが書いたとおりに保たれます。

## IDE との同期

- **外部での変更:** アプリは 2 秒ごとにファイルを確認します。変更があり、未保存の変更がなければ、画面が自動で再読み込みされます。未保存の変更がある場合は、**相手の変更を読み込む** (自分の変更を破棄) か **自分のものを残す** (保存時に、新しいファイルとの差分を表示) を選べます。
- **保存:** 必ず先に差分を表示し、ファイルが確認したときのままの場合だけ書き込みます。前のバージョンは履歴に入り、書き込みはアトミックです。
- **元に戻す・やり直す:** エディター内で `Ctrl+Z` と `Ctrl+Y` が使えます。

## プレビューとサンプルデータ

- **静的プレビュー:** LocDev はサンプルデータ (`$user->name`、`$order['id']`、`?? 'default'`、`config()`、`__()`、`route()`、`date('Y')`) を置き換え、プロジェクトのコンポーネントを展開します。**何も実行しません**。Blade のロジックは評価しないので、`@if` の両方の分岐が表示され、画面にもその旨が出ます。選択中のブロックはプレビューで強調表示されます。
- **フレームワークによるプレビュー (Laravel):**
  - レンダリングするのは Laravel 自身で、`view()` または mailable の `Markdown::render` を使います。
  - **別のプロセス**で動き、環境は最小限 (サイトの PHP、`HOME`、`APP_ENV=local`、メールの送信先は Mailbox)、制限時間は 25 秒、出力も制限されます。
  - 保存していない内容は LocDev の一時ファイルに書かれ、プロジェクトには書かれません。
  - `vendor/` のインストールが必要です。
- **表示:** デスクトップまたはモバイル、生成された HTML、テキスト版、書き込まれるファイル。
- **サンプルデータ:** テンプレートの変数から提案され、JSON で編集でき、LocDev がプロジェクトの外に保存します。**テスト送信** でレンダリングして Mailbox に送ります。

## ジェネレーター

`locdev new email <name>` はフレームワークの構成に従い、既存のファイルを**上書きしません**。

- **Laravel:** Laravel 自身のジェネレーター `php artisan make:mail <Name>Mail --view=emails.<name>` (または `--markdown`) を実行し、作られたビューにブロックのテンプレートを入れます。PHP や `vendor/` がない場合はビューだけを作り、Mailable を作るコマンドを表示します。
- **コンポーネント:** `resources/views/components/mail/<name>.blade.php`。`@props` と説明のコメント付きです。`button`、`header`、`footer` には専用のテンプレートがあります。
- **ほかのスタック:** `emails/<name>.html` と `emails/components/<name>.html`。

アプリでは **新しいテンプレートまたはコンポーネント** に同じ機能があります。`--site` でプロジェクトを明示的に選べます。

## 制限

- 純粋な HTML のコンポーネントは、まだビジュアルブロックになりません。コードとして編集してください。
- コードエディターにはシンタックスハイライト (Blade、HTML、Markdown)、検索 (`Ctrl+F`)、元に戻す機能がありますが、テンプレートの変数の補完はありません。
- フレームワークによるプレビューは Laravel だけです。ほかのスタックでは、静的プレビューかフレームワーク自身のツールを使ってください。
