# リクエストメトリクス

LocDev のプロキシを通るサイトへのリクエスト (`<サイト>.test`、そのサブドメイン、HTTP と HTTPS) はすべて数えられます。サイトの **メトリクス** タブ (または `locdev metrics <サイト>`) は 3 秒ごとに更新され、次を表示します。

- リクエスト数と 5xx エラー
- レイテンシ (平均、p50、p95、p99、最遅): 直近 1,000 件のリクエストでの、レスポンスヘッダーまでの時間
- 直近 1 時間の毎分のリクエスト数
- 区分ごとのステータスコードと、サイトのサーバーが応答しなかったリクエスト
- アクセスの多いパス (メソッドとパス、クエリなし) と平均時間、エラー
- 最新 100 件のリクエスト

## 数えるもの、数えないもの

数値はデーモンのメモリにだけあり、ディスクに書かれることもどこかへ送られることもありません。デーモンの再起動、または **リセット** (`locdev metrics <サイト> --reset`) でゼロから数え直します。`127.0.0.1:<ポート>` への直接のリクエストはプロキシを通らないため数えません。WebSocket のアップグレードは 1 件 (101) と数えます。

メモリはサイトごとに上限があります: レイテンシ 1,000 件、60 分、サンプル 100 件、異なるパス 300 件 (それ以上のパスも合計には含まれます)。

```bash
locdev metrics
locdev metrics shop --json
locdev metrics shop --reset
```

5xx の応答と応答しないサーバーは [Debug Center](/docs/debug-center) にも表示されます。
